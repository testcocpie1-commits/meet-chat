# 遇见 / 遇見

无需注册的中文匿名聊天网站。Node.js 24+，生产运行无需第三方依赖。

## 启动

```sh
cd /workspace/meet-chat
cp .env.example .env
# 编辑 .env，为 ADMIN_PASSWORD 设置至少 16 字符的随机密码。
npm start
```

默认监听 3000 端口。聊天入口 `/`，管理员入口 `/admin`。后台密码未设置时无法登录，没有默认密码。正式部署请使用 HTTPS 反向代理，并设置 `COOKIE_SECURE=true`。在单层反向代理后请设置 `TRUST_PROXY=true`，否则所有用户会共用代理 IP 的限速额度。代理需要保留 Host，转发同源 API；客户端每 1.5 秒轮询一次。不要缓存 API。数据目录 `data/` 必须挂载持久磁盘并定期备份。

## 已实现

- 匿名 HttpOnly 会话，无需注册，关闭页面 45 秒后清理会话并通知对方离开。
- 双方性别偏好匹配；性别由使用者自行声明。密语使用 SHA-256 摘要分池，不保存原文。密语并不是加密或身份验证。
- 实时文字聊天、消息引用、结束及重新配对、固定 😀 😂 🥰 😢 👍 五个表情按钮。允许手动输入其他表情及语言。
- 简体、繁体界面切换，保留语言选择，兼容手机。
- 举报附最近最多 30 条消息，立即断开，当前会话内避免再次配对。对方离开后仍可举报刚结束的对话。
- 管理员登录、在线/等待统计、举报证据查看、驳回、标为处理、设备限制 24 小时、退出登录。举报及封禁用 SQLite 持久保存。
- 消息及配对操作限速、同一 IP 每分钟最多新建 30 个会话、后台登录失败限速（按 IP，成功后重置）、同源写入检查、消息长度限制。消息使用 textContent 渲染，避免 HTML 注入。
- Google AdSense：配置 `ADSENSE_CLIENT=ca-pub-…` 和 `ADSENSE_SLOT=…` 后加载广告。未配置时仅显示占位。真实广告仍需站点审核；收益、审核和填充率不由本项目保证。

## 测试

```sh
npm test
# 浏览器测试需要安装开发依赖和 Chromium：
npm ci
npx playwright install chromium
npm run test:browser
```

API 集成测试覆盖双向筛选、密语隔离、消息与引用、举报证据、后台认证、封禁、断开和跨站请求拦截。浏览器测试验证两个独立游客聊天、简繁切换、举报及后台操作和手机布局。

## 第一版边界

这是可运行的单实例 MVP。会话、排队和普通聊天只在进程内存中，最近最多 100 条，重启后消失；结束后最多等待会话超时清理。举报证据则存 SQLite，管理员需按实际隐私政策安排保留与删除。普通对话并非端到端加密，服务器可读取内容。

设备封禁依赖匿名 Cookie，清除 Cookie 可绕过，不能当成强身份封禁。上线前仍需配置边缘限流/人机验证、监控、备份、适用地区的隐私与广告同意流程，并对预期人数做压测。Google 对用户生成内容和广告位置有审核要求，建议先确认政策再开启真实广告。

当前没有多服务器共享队列、持久聊天历史、图片、好友或账号功能。新增这些功能需要 Redis/数据库架构调整。与 WooTalk 的后台实现或页面没有源码关系。
